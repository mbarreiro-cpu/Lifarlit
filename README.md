# Lifarlit

## Descripción del proyecto

Lifarlit es una aplicación desarrollada con Flutter para consultar información de productos de farmacia.

## Funcionalidades

- Pantalla principal con mensaje de bienvenida.
- Categorías de Vitaminas e Higiene.
- Listado de productos destacados.
- Detalle de productos con descripción y precio.
- Formulario de consulta.
- Navegación entre pantallas mediante Navigator.

## Tecnologías utilizadas

- Flutter
- Dart
- Visual Studio Code
- Git

## Cómo ejecutar el proyecto

Ejecutar los siguientes comandos desde la carpeta del proyecto:

flutter pub get
flutter run -d chrome

## Uso del formulario

El formulario muestra una confirmación en pantalla. Actualmente, no envía los datos a un servidor.
